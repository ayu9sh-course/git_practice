# Financial Loan Risk – Project Submission

## Project Report
This repository contains a Jupyter Notebook submission for a financial loan risk analysis project.

### Objective
Build and evaluate a workflow to analyze loan applicant information and support risk-oriented decision making.

### Deliverable
- `financial_loan_risk_summative.ipynb`: main notebook with the project workflow, analysis, and results.

## How to Run
1. Install Python 3.9+ and Jupyter.
2. Open the notebook:
   - `jupyter notebook financial_loan_risk_summative.ipynb`
3. Run all cells from top to bottom.
